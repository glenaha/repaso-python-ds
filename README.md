## Repaso Python para Data Science

Práctica inicial del curso Data Science II: Machine Learning para la Ciencia de Datos.

El notebook `practica_python.ipynb` incluye:
- Tarea 1: Definición de variables de distintos tipos y uso de f-strings.
- Tarea 2: Bucle y condicional para clasificar precios como "Caro" o "Económico".
- Tarea 3: Diccionario `almacen` con productos y su stock.
- Tarea 4: Función `resumen_estadistico` que devuelve suma, promedio y cantidad.
